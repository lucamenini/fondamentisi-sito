# fondamentisi-sito

Sorgenti del sito [fondamentisi.eu](https://fondamentisi.eu) del libro *Fondamenti di Sistemi Informativi per gli studenti dei corsi di laurea in Ingegneria Gestionale* (Luca Menini, Niccolò Iandelli, Diletta Tosetto, 1ª edizione 2027).

Il sito è pubblicato con GitHub Pages a partire dal ramo `main`. Le pagine sono in Markdown e si possono modificare direttamente su GitHub:

- `index.md` · presentazione del libro;
- `soluzioni/` · soluzioni delle domande e degli esercizi (PDF, dall'uscita del libro);
- `aggiornamenti/` · aggiornamenti e correzioni dopo la stampa.

Il testo del libro non è pubblicato in questo repository.
